# Vendored: RoverServoLib

These files are a vendored snapshot of **RoverServoLib**, used by OpenArm-C for
the Ranger Air rover (`ranger_air_control/`) and DS-2C servo (`ds2c-servo/`)
protocol reference (ported to C in `../openarm-c/ranger.*` and `ds2c.*`).

- Source: https://github.com/jackbiggins-dev/RoverServoLib.git
- Snapshot commit: 670d5d98dcfb681bb47f58334e94f1bba5bd6651

To refresh, re-clone upstream over this directory and re-copy.
